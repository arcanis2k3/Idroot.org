Drei Schritte zu deinem
dauerhaften Handle

01

Identität verifizieren

Schließe eine schnelle Identitätsprüfung über Didit ab. Gesichtsscan + Ausweisdokument — dauert unter 2 Minuten. Wir speichern nur einen Verifizierungsstatus und einen Zeitstempel.

Powered by Didit KYC
02

Handle wählen

Wähle deinen @name.idroot.org-Handle. Er gehört dir — nicht an eine App oder Plattform gebunden, funktioniert im gesamten AT-Protocol-Netzwerk.

03

Auf Bluesky aktivieren

Gehe zu Bluesky-Einstellungen → Handle ändern → trage deinen neuen @name.idroot.org-Handle ein. Unser System erkennt den Wechsel automatisch innerhalb von 48 Stunden und bestätigt deinen Handle dauerhaft.

Warum idroot

Besitz deine Adresse im offenen Web

Dein Bluesky-Handle ist deine Identität. Mach daraus etwas, das für dich spricht — und dem du vertrauen kannst.

  • Echte Identität, minimale Daten
    KYC-Verifizierung ohne Überwachungsspur. Wir speichern keine Dokumente.
  • Portabel im Fediverse
    Funktioniert auf Bluesky, Bapu und jeder App, die heute oder morgen auf AT Protocol aufbaut.
  • Kostenlos, für immer
    Verifizierte Nutzer erhalten ihren Handle ohne Kosten. Kein Abo, kein Ablaufdatum, kein Haken.
  • Von der Community vertraut
    Ein verifiziertes Häkchen zeigt, dass du real bist — kein Bot, kein Imitator.
  • Auf GitHub sponsern
