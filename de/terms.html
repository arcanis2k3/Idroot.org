2. Beschreibung des Dienstes

idroot.org stellt Benutzern, die die Identitätsverifizierung erfolgreich abgeschlossen haben, verifizierte AT Protocol-Handles im Format @benutzername.idroot.org zur Verfügung.

Der Dienst funktioniert wie folgt:

  1. Identitätsverifizierung. Der Benutzer schließt die Identitätsverifizierung über Didit ab. Bei einem erfolgreichen Ergebnis wird ein Benutzerkonto auf der idroot.org-Plattform erstellt (unterstützt vom Bapu-Backend, betrieben vom selben Verantwortlichen).
  2. Handle-Zuweisung. Das verifizierte Handle wird sofort zugewiesen und dauerhaft mit der AT Protocol-DID des Benutzers verknüpft. Es gibt kein zeitlich begrenztes Reservierungsfenster — das Handle gehört Ihnen nach der Verifizierung.
  3. Aktivierung. Der Benutzer kann das Handle direkt über er seine AT Protocol-Profileinstellungen (z. B. Bluesky-Einstellungen → Handle ändern) so aktualisiert, dass sie auf das ausgegebene Handle verweisen.
  4. Kontoverwaltung. Zur Verwaltung Ihres Handles ist ein Benutzerkonto auf dashboard.idroot.org erforderlich. Über das Benutzernamen ändern oder Ihr Handle vollständig freigeben.

Der Dienst umfasst insbesondere: die Überprüfung der Benutzeridentität über Didit; die Bereitstellung eines DNS-TXT-Eintrags, der Ihren Benutzernamen mit Ihrer AT Protocol-DID verknüpft; die Erstellung und Pflege eines Benutzerkontos für die Handle-Verwaltung; und die Bestätigung der Handle-Aktivierung durch Überprüfung, ob Ihr AT Protocol-Profil aktualisiert wurde.

4. Handle-Zuweisung und Aktivierung

Nach erfolgreicher Identitätsprüfung wird Ihr gewähltes Handle sofort zugewiesen. Der DNS-TXT-Eintrag wird unverzüglich bereitgestellt. Sie können das Handle über dashboard.idroot.org oder direkt über Ihren AT Protocol-Client (z. B. Bluesky-Einstellungen → Handle ändern) aktivieren. Es gibt kein zeitlich begrenztes Reservierungsfenster.

Sie können Ihr aktives Handle jederzeit über dashboard.idroot.org in einen anderen verfügbaren Benutzernamen ändern, sofern dieser verfügbar ist. Sie können Ihr Handle auch jederzeit freigeben. Freigegebene Handles stehen anderen verifizierten Benutzern zur Verfügung.
